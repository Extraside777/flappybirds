# Flappy Bird

Небольшая игра на Python и Pygame с анимированным меню, фоном и игровыми спрайтами.

## Запуск

1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Запустите игру:

   ```bash
   python src/main.py
   ```

## Управление

- **Пробел / стрелка вверх / клик мышью** — взмахнуть крыльями.
- **Escape** — вернуться в меню.
- После столкновения нажмите, чтобы начать заново, или выберите меню.

## Структура проекта

- `src/` — игровой код и система спрайтов.
- `assets/images/` — исходные изображения, используемые проектом.
- `assets/sprites/` — подготовленные спрайты, слои фона и описание анимаций.
- `assets/fonts/` — шрифт игры.
- `tools/` — скрипт подготовки спрайтов.

## Изменение и подготовка спрайтов

Параметры кадров, скоростей и слоёв находятся в `assets/sprites/manifest.json`.
Для повторной генерации спрайтов установите зависимости из `tools/requirements.txt` и выполните:

```bash
python tools/make_sprites.py
```
