# Flappybirds

Учебный командный проект **Temshik Team** — клон Flappy Bird на **Python + Pygame** с собственными механиками.

## Первый прототип

Сейчас проект содержит минимально играбельную версию:

- окно игры 900×600;
- птица и гравитация;
- прыжок по `Space` или ЛКМ;
- случайно генерируемые трубы;
- столкновения;
- подсчёт очков;
- экран Game Over;
- перезапуск через `R`.

## Запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить:

```bash
python src/main.py
```

## Управление

- `SPACE` / ЛКМ — взмах;
- `R` — перезапуск после смерти;
- `ESC` — выход.
