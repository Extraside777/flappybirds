# Flappy Bird для Android

Порт гри з `src/` на Java (Android Studio проєкт). Логіка, числа і спрайти -- ті самі, що й у пайтон-версії:
картинки, музика, звуки і шрифт беруться прямо з `../assets` (одне джерело для обох версій).

Що змінено під телефон:

- керування дотиком: тап -- стрибок (можна двома пальцями по черзі), повзунки тягнуться пальцем, магазин гортається;
- гра на весь екран без чорних смуг і однаково виглядає на будь-якому телефоні/планшеті: поле 400 px завширшки,
  меню і панелі -- по центру, земля -- завжди внизу екрана, а монети, рахунок, рівень і шестерня -- біля верхнього
  краю (нижче вирізу камери) і біля бокових країв; зайва висота йде на небо, місця для польоту більшає порівну
  зверху і знизу;
- пауза, коли гру згорнули, опустили шторку або натиснули «назад» (з паузи можна вийти в меню);
- кнопка «назад»: з магазину/налаштувань -- у меню, з меню -- вихід;
- рядок «розмір вікна» в налаштуваннях прибрано; мова за замовчуванням -- як на телефоні (українська або англійська);
- екран 60 Гц (гра рахує кадри по 1/60 с, як у пайтоні), прогрес зберігається у пам'яті застосунку;
- у меню під монетками -- кнопка «+5 монет за рекламу» (Google AdMob, див. нижче): 5 переглядів за добу,
  під кнопкою видно, скільки ще лишилось, а коли ліміт вичерпано -- таймер до наступного.

## Зібрати APK

Відкрити папку `android` в Android Studio і натиснути *Build > Build APK(s)*, або з консолі:

```bash
cd android
./gradlew assembleRelease
```

Готовий файл: `app/build/outputs/apk/release/app-release.apk`.

Release підписується ключем `flappy-release.jks` з паролями в `keystore.properties` (обидва файли -- лише локально,
в git їх нема). Збережіть їх: оновлення гри встановиться поверх старої версії тільки з тим самим ключем.
Якщо `keystore.properties` нема, release підписується debug-ключем.

Шлях до проєкту містить кирилицю, тому в `gradle.properties` увімкнено `android.overridePathCheck`.
Тест (`./gradlew testDebugUnitTest`) з такого шляху не стартує -- запускайте його з диска з латинським шляхом
(наприклад, `subst X: <папка проєкту>`). Він проходить усі екрани і зберігає їх у `app/build/screens/`.

Іконки застосунку: `python tools/make_android_icons.py`.

## Реклама (Google AdMob)

Кнопка «+5 монет» показує рекламу з винагородою: монети даються, лише коли ролик додивились до кінця;
5 переглядів за 24 години (кожен перегляд «звільняється» через добу після себе). Ролик вантажиться заздалегідь,
поки гравець у меню; поки він не готовий (або нема інтернету) -- кнопка темніша, а натискання пише
«РЕКЛАМА ЩЕ НЕ ГОТОВА». Код: `AdMob.java` (Google Mobile Ads SDK + згода UMP), логіка кнопки -- `Game.java`.

У `admob.properties` -- справжні ID застосунку «Flappy Bird» і блоку «Монети за рекламу» з AdMob
(debug-збірка все одно показує тестову рекламу). Повідомлення про згоду (GDPR) в AdMob опубліковано.
Сайт розробника -- <https://extraside777.github.io> (репозиторій `Extraside777/Extraside777.github.io`,
локальна копія -- `site/`): там політика конфіденційності (`/privacy.html`, її посилання потрібне в Google Play)
і `app-ads.txt`. Цю адресу вкажіть у Google Play як сайт розробника.

Як це налаштовувалось (якщо доведеться повторити для іншої гри):

1. Зареєструйтесь на <https://admob.google.com> (той самий Google-акаунт, що й для Google Play),
   заповніть платіжні дані і податкову інформацію (без них виплат не буде).
2. *Застосунки -> Додати застосунок -> Android*. Якщо гри ще нема в Google Play -- «ні», потім її можна
   прив'язати. Скопіюйте **ID застосунку** (`ca-app-pub-...~...`, з тильдою).
3. *Рекламні блоки -> Додати -> З винагородою* (Rewarded). Нагорода: 5, «монети» (це лише підпис -- скільки
   давати, вирішує гра). Скопіюйте **ID блоку** (`ca-app-pub-.../...`, з косою рискою).
4. Впишіть обидва ID у `android/admob.properties` (`appId=` і `rewardedId=`) і зберіть release.
   Debug-збірка все одно показує тестову рекламу -- так і треба.
5. *Конфіденційність і повідомлення -> GDPR*: створіть і опублікуйте повідомлення про згоду. Без нього гравці
   з ЄС/Великої Британії реклами не побачать. Гра сама покаже цю форму, а в налаштуваннях у них з'явиться
   кнопка «КОНФІДЕНЦІЙНІСТЬ» (Google вимагає, щоб згоду можна було змінити).
6. У Google Play Console: «Застосунок містить рекламу» -- так; у розділі «Безпека даних» вкажіть, що
   рекламний SDK збирає ідентифікатор пристрою. Додайте сайт розробника і викладіть на нього `app-ads.txt`
   (рядок дасть AdMob у *Застосунки -> app-ads.txt*).

Важливо: **не клацайте свою справжню рекламу** -- AdMob за це блокує акаунт. Для перевірки на своєму
телефоні ставте debug-збірку або додайте телефон у *Налаштування -> Тестові пристрої*. Новий рекламний блок
може кілька годин (інколи день-два) не віддавати рекламу -- тоді кнопка просто лишається темнішою.

Google Mobile Ads SDK потребує Android 7.0+, тому `minSdk` тепер 24. Під час release-збірки lint пише червоні
рядки `e: ... Module was compiled with an incompatible version of Kotlin` -- це лише lint цієї версії Android
Gradle Plugin не розуміє новий SDK; збірка проходить, APK робочий (зникне після оновлення Android Studio / AGP).
