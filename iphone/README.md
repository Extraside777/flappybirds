# Flappy Bird для iPhone

Це та сама гра, перенесена на HTML5/JavaScript (`web/`, порт Android-версії), у застосунку
[Capacitor](https://capacitorjs.com). Картинки, музика і звуки -- з `assets/`, як в інших версіях.
Реклама за монети -- Google AdMob (плагін `@capacitor-community/admob`), ID -- у `admob.properties`
(поки тестові: реклама з написом «Test Ad»).

## Перевірити в браузері (на комп'ютері)

```bash
python tools/serve_web.py
```

і відкрити <http://localhost:8765>. У браузері реклами нема -- кнопка «+5» дає монети одразу (як на ПК).

## Зібрати .ipa

Mac не потрібен: збирає GitHub на своєму Mac-сервері (`.github/workflows/ios.yml`, для публічного
репозиторію -- безкоштовно). Запускається сам після `git push` змін гри, або вручну:
GitHub -> вкладка **Actions** -> **iPhone (.ipa)** -> **Run workflow**. Через ~10 хв на сторінці запуску
внизу, у **Artifacts**, буде `FlappyBird-ipa` -- завантажте і розпакуйте zip, усередині `FlappyBird.ipa`.

## Поставити на iPhone (з Windows, безкоштовний Apple ID)

1. Встановіть на комп'ютер **iTunes** і **iCloud** -- версії з сайту Apple (не з Microsoft Store) --
   і **Sideloadly** (<https://sideloadly.io>).
2. Підключіть iPhone кабелем, на телефоні натисніть «Довіряти цьому комп'ютеру».
3. У Sideloadly: перетягніть `FlappyBird.ipa`, впишіть свій Apple ID, натисніть **Start**
   (пароль Apple ID вводите в самому Sideloadly).
4. На iPhone: **Параметри -> Загальні -> VPN і керування пристроєм** -> ваш Apple ID -> **Довіряти**.
   На iOS 16+ ще треба увімкнути **Параметри -> Приватність і безпека -> Режим розробника** (телефон
   перезавантажиться).

З безкоштовним Apple ID гра працює **7 днів**, потім її треба поставити ще раз тим самим способом
(прогрес не губиться, якщо не видаляти гру). Одночасно -- не більше 3 таких застосунків.
З платним Apple Developer ($99/рік) можна ставити через TestFlight без цього обмеження і випустити гру
в App Store -- тоді в AdMob треба додати окремий застосунок iOS і вписати його ID в `admob.properties`.
